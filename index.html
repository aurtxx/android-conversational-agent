Engineered for Physical Android Devices

Zero emulators needed. Connects directly to hardware over USB debugging or Wi-Fi.

🛡️

Safe Keyboard Guardrail

Interrogates dumpsys input_method for mInputShown=true and sends safe KEYCODE_BACK dismissals to prevent UI occlusion or duplicate typing loops.

⚡

RapidOCR Screen Parser

Captures live display buffers via exec-out screencap -p and clusters text boxes with sub-second ONNX OCR, enabling instant perception without waiting on slow dumps.

🧠

High-EQ Hinglish Reasoning

Conversational engine with an anti-repetition topic state machine. Understands gaming slang (Clash Squad, MP40), hostel culture, and local Gujarati cues without circular prompts.

👥

Zero Cross-Talk Multi-Target

Manages concurrent, independent conversations with distinct contacts using strict identity verification to eliminate any accidental message leaks.

📴

Offline Local Neural Brain

Integrated with ultra-compact ~92MB quantized GGUF weights (SmolLM2-135M) via llama-cpp-python, providing completely private, offline dialogue analysis.

🎙️

Multi-Speaker Speech Synthesis

Generates multi-turn vocal conversations using gTTS and audio pitch/tempo modulation via ffmpeg for natural spoken dialogues.

Launch Autonomous Agent in Seconds

Plug in your Android phone with USB Debugging enabled and run the unified CLI:

python run.py --mode autonomous --profile config/subjects/krupali_ni.json --turns 50
